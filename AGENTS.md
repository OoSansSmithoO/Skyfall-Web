# Skyfall Web AI Operating Charter

`D:\Github\Skyfall Web\` is the sole trusted project workspace. Work autonomously on ordinary project-local development while following these boundaries:

- Do not access unrelated repositories, personal files, or locations outside this workspace by default.
- Obtain explicit approval before public network access, dependency installation, or external service use.
- Obtain explicit approval before Git mutations, including add, commit, branch operations, merge, rebase, reset, clean, tag changes, push, or force-push.
- Obtain fresh explicit approval before deployment or any GitHub remote, Actions, hosting, or DNS modification.
- Do not access credentials, tokens, API keys, certificates, SSH or GPG keys, browser credential stores, password managers, or other secrets.
- Preserve existing user work and inspect the working tree before making changes.
- Inspect unfamiliar scripts before executing them.
- Prefer small, targeted changes over broad rewrites.
- After meaningful code changes, run the existing lint, type-check, and production-build commands when permitted.
- Keep public-facing documentation useful without exposing unnecessary proprietary implementation details.
- Treat every approval as narrow and operation-specific; never reuse it for unrelated work.
